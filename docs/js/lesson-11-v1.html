textContent 

el.textContent = '<b>hei</b>';
el.innerHTML                   → '&lt;b&gt;hei&lt;/b&gt;'
el.children.length             → 0   it is text, not markup

el.innerHTML = '<b>hei</b>';
el.children.length             → 1   it is now an element

innerHTML will not run a <script> tag — but that is not safety.
an onerror on an image runs perfectly well.
el.innerHTML = '<img src=x onerror=...>';   this executes

so: textContent for anything that came from a person.
