three keywords, and only two of them are worth typing

const pris = 199;      the name will never point elsewhere
let   antall = 1;      the name will
var   gammel = true;   the one from before 2015
const 

const pris = 199;
pris = 249;                 TypeError: assignment to constant variable

but from lesson 2: it binds the name, not the contents
const kunde = {};
kunde.navn = 'Ada';          fine
kunde = {};                    TypeError

and it must be given a value on the spot
const x;                      SyntaxError: missing initializer
let 

let antall = 1;
antall = 2;                  allowed — that is the whole difference

let senere;                   allowed without a value → undefined

but not twice in the same scope
let a = 1;
let a = 2;                    SyntaxError: already declared
var 

var does not see blocks. only functions.

function f() {
  { var v = 'leaked out'; }
  return v;                  → 'leaked out'
}

function g() {
  { let l = 'stayed in'; }
  return l;                  ReferenceError: l is not defined
}

and it can be declared twice without a word of complaint
var a = 1;
var a = 2;                    allowed — which hides typos
hoisting 

a var exists from the top of its function, holding undefined
function f() {
  typeof x;                  → 'undefined'   already known
  var x = 1;
}

a function declaration is hoisted whole — you can call it early
hilse();                       → works
function hilse() { ... }

a function stored in a var is not
hilse();                       TypeError: hilse is not a function
var hilse = function() { ... };   the var is undefined until this line
TDZ 

let and const are hoisted too — but unusable until their line runs

function f() {
  typeof y;                  ReferenceError: cannot access 'y' before initialization
  let y = 1;
}

note what that means: typeof does not save you here.
on an undeclared name it returns 'undefined'; in the dead zone it throws.
for (let i) 

one shared i — every function sees the value it ended on
const fns = [];
for (var i = 0; i < 3; i++) fns.push(() => i);
fns.map(f => f())              → [3, 3, 3]

a fresh j for every turn of the loop
const fns2 = [];
for (let j = 0; j < 3; j++) fns2.push(() => j);
fns2.map(f => f())             → [0, 1, 2]
globals 

assigning to a name you never declared
function f() { antall = 1; }   sloppy mode: makes a global
                                 strict mode: ReferenceError

modules are always strict, so this is an error in any real project

and at the top level of a classic script
var a = 1;   window.a        → 1
let b = 1;   window.b        → undefined
