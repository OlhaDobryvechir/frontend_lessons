two loops that look almost the same and are not

for (const v of ['a', 'b']) ...    v is 'a', then 'b'      the values
for (const k in ['a', 'b']) ...    k is '0', then '1'      the keys, as text
for 

for (let i = 0; i < liste.length; i++) {
  ...
}
      │            │                │
      │            │                └ after every turn
      │            └ checked before every turn

use let, not var — lesson 3 showed why
while 

when you cannot say up front how many turns there will be
while (kø.length > 0) {

do...while tests afterwards, so the body always runs once
let forsøk = 0;
do { forsøk++; } while (forsøk < 3);

while (false) { ... }      runs 0 times
do { ... } while (false);   runs 1 time
for...of 

for (const pris of priser) { ... }     no counter, no length, no index

need the index as well?
for (const [i, pris] of priser.entries()) { ... }

it works on anything iterable — strings, Map, Set, NodeList
for (const tegn of 'hei') { ... }

but not on a plain object
for (const v of { a: 1 })          TypeError: is not iterable
for...in 

it walks keys, and keys are text (lesson 2)
for (const k in ['a', 'b', 'c'])   k is '0', '1', '2'

and it finds everything, not just the indexes
const a = ['a', 'b'];
a.notat = 'ikke en indeks';
for (const k in a)               '0', '1', 'notat'
for (const v of a)               'a', 'b'        unaffected

the order is not the order you wrote them in
const o = {}; o.b = 1; o['2'] = 1; o.a = 1; o['1'] = 1;
Object.keys(o)                   → ['1', '2', 'b', 'a']

for objects, prefer the explicit form
for (const [k, v] of Object.entries(o)) { ... }
break continue 

break      leave the loop entirely
continue   skip to the next turn

both only leave the innermost loop — unless you name one
ytre: for (const a of rader) {
  for (const b of a.celler) {
    if (b.tom) continue ytre;   next row, not next cell
  }
}
forEach 

liste.forEach(v => { ... });        do something with each
liste.map(v => v * 2);              build a new array
liste.filter(v => v > 0);            build a shorter one
liste.find(v => v.id === 7);         the first match, or undefined

but you cannot leave a forEach early
liste.forEach(v => { if (v) break; });   SyntaxError
liste.forEach(v => { if (v) return; });  skips one, keeps going

when you do need to stop early
liste.some(v => v.id === 7);         stops at the first true
for (const v of liste) { if (...) break; }
pitfalls 

the condition is re-read every single turn
const liste = [1, 2, 3];
for (let i = 0; i < liste.length; i++) {
  liste.push(i);               the end moves away faster than i reaches it
}                              this never finishes

removing while walking forwards skips elements
for (let i = 0; i < liste.length; i++) {
  if (skalFjernes(liste[i])) liste.splice(i, 1);   the next one slides into i
}

walk backwards, or build a new list instead
const beholdt = liste.filter(v => !skalFjernes(v));
