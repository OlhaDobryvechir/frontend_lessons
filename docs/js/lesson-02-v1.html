lesson 1 was the values that get copied. these get shared.

let a = { x: 1 };
let b = a;                  not a copy — the same object, twice
b.x = 2;
a.x                          → 2
object 

all three are objects. the differences are conveniences on top.

{ navn: 'Ada' }          a plain object — named slots
[10, 20, 30]               an array — numbered slots, in order
function f() {}            a function — an object you can call
typeof 

typeof {}                 → 'object'
typeof []                 → 'object'    no help at all
typeof function(){}     → 'function'  the one exception
typeof null               → 'object'    the bug from lesson 1

so to recognise an array there is a separate question
Array.isArray([])            → true
Array.isArray({})            → false
reference 

a primitive is copied
let n = 1;
function endre(tall) { tall = 99; }
endre(n);   n                → 1     untouched

an object is shared
const liste = [1];
function leggTil(a) { a.push(2); }
leggTil(liste);   liste      → [1, 2]   changed from inside

and const does not protect the contents
const c = {};
c.foo = 1;                  allowed — const binds the name, not the object
c = {};                      TypeError — this is what const stops
array 

const priser = [199, 299, 399];
priser[0]                   → 199    counting starts at zero
priser.length                → 3

underneath, the indexes are ordinary keys — as text
Object.keys([10, 20])       → ['0', '1']

length is not a count, it is the highest index plus one
const a = [];
a[10] = 1;   a.length      → 11
a.length = 1;                writing to it truncates the array

every key is text, whatever you write
const o = {};
o[1] = 'a';
Object.keys(o)               → ['1']

function 

a function is a value. it can go wherever a value can go.

const hilsen = function() { ... };   stored in a variable
knapp.addEventListener('click', hilsen);  handed to something else
[3, 1, 2].sort(sammenlign);           passed as an argument

and it carries properties, like any other object
function sum(a, b) { return a + b; }
sum.name                     → 'sum'
sum.length                   → 2      how many arguments it declares
=== 

primitives compare by content
'hei' === 'hei'              → true

objects compare by identity — are these the same one?
[] === []                    → false
({}) === ({})                → false
[1, 2] === [1, 2]            → false   same contents, two objects

const x = {};
const y = x;
x === y                      → true    one object, two names
