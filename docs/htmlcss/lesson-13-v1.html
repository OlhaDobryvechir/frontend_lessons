width: 400px;       what you asked for
max-width: 300px;   but never wider than this
min-width: 500px;   and never narrower than this

the element ends up 500px wide. min beats max beats width.
box-sizing 

the default: the number is the content box only
.box { box-sizing: content-box; width: 200px; padding: 20px; border: 2px solid; }
→ occupies 2 + 20 + 200 + 20 + 2 = 244px

border-box: the number is the whole visible box
.box { box-sizing: border-box; width: 200px; padding: 20px; border: 2px solid; }
→ occupies 200px, and the content gets 156px

which is why almost every project begins with this line
*, *::before, *::after { box-sizing: border-box; }
auto 

width: auto     a block fills whatever room its parent gives it
height: auto    a block is exactly as tall as its content

the same asymmetry that made height: 50% fail in lesson 12
max-width 

the responsive workhorse: follow the window, then stop
.container { width: 100%; max-width: 60rem; }

and the one line that keeps images inside their box
img { max-width: 100%; height: auto; }
min-width 

a floor, so the column never becomes unusable
.sidebar { width: 25%; min-width: 240px; }

min-height keeps an empty box from collapsing
.panel { min-height: 8rem; }
min > max > width 

width: 400px;  max-width: 300px;                     → 300px
width: 400px;  min-width: 500px;                     → 500px
width: 400px;  max-width: 300px;  min-width: 500px;  → 500px

the order is fixed: apply width, clamp with max, then clamp with min.
whoever runs last wins, so min-width always has the final say.
min-content 

width: min-content   as narrow as possible without overflowing
width: max-content   as wide as the content wants, never wrapping
width: fit-content   max-content, capped by the space available

the function form takes a limit of your own, but browsers
accept it on grid tracks rather than on width
grid-template-columns: fit-content(40ch)
min-width: 0 

the classic: a flex item that refuses to shrink
.item { flex: 1; }                  long text pushes the row wider

the fix, and it looks like it should do nothing
.item { flex: 1; min-width: 0; }   now it can shrink and wrap

because on a flex item min-width: auto means min-content, not zero
