same-origin 

scheme + host + port must all three match

https://altibox.no/a      https://altibox.no/b        same origin
https://altibox.no/       http://altibox.no/          different scheme
https://altibox.no/       https://www.altibox.no/     different host
https://altibox.no/       https://altibox.no:8443/    different port
