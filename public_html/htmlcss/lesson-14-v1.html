four properties, and one of them quietly overwrites the others

text-align:  center;
font-size:   1rem;
font-weight: 700;
font:        1rem system-ui;   ← the weight above is now 400 again
text-align 

text-align: start;     where the reading direction begins
text-align: end;       where it finishes
text-align: center;
text-align: justify;   stretch every line but the last

this centres the text inside the card
.card { text-align: center; }

this centres the card itself
.card { width: 40rem; margin-inline: auto; }
font-size 

font-size: 16px;     fixed — ignores what the reader chose
font-size: 1rem;     relative to the root — follows the reader
font-size: 1.25em;   relative to the parent — compounds when nested
font-size: 125%;     exactly the same as 1.25em

em compounds, and that is the whole difference
.step        { font-size: 1.5em; }   16px → 24px
.step .step  { font-size: 1.5em; }   24px → 36px
font-weight 

font-weight: 400;   the same thing as normal
font-weight: 700;   the same thing as bold
font-weight: 100 … 900

these two are relative to whatever the parent has
font-weight: bolder;
font-weight: lighter;
font-family 

font-family: 'Nunito Sans', 'Segoe UI', system-ui, sans-serif;
             └ quoted, because the name contains a space
                                                  └ always end with a generic
font 

size and family are required, and the order is fixed
font: 700 1rem/1.5 system-ui, sans-serif;
      │    │    │    └ family
      │    │    └ line-height
      │    └ size
      └ weight

the trap: anything left out is reset, not kept
.title { font-weight: 700; font: 1rem system-ui; }   → weight is 400
.title { font: 1rem system-ui; font-weight: 700; }   → weight is 700
line-height 

a parent at 16px, with a child at 32px

line-height: 1.5;     the child inherits the ratio  → 48px
line-height: 150%;    the child inherits 24px       → 24px
line-height: 24px;    the child inherits 24px       → 24px

the last two crush large text. write the number on its own.
inherit 

inherited       color, font-family, font-size, font-weight,
                line-height, text-align, letter-spacing

not inherited   width, height, margin, padding, border, background
