#priser   an id — the one element with that name

P  { ... }                    matches <p> too — tag names ignore case in HTML
.class 

.price { font-weight: 700; }

<p class="price">499 kr</p>              matches
<span class="price">499 kr</span>        matches — any element at all
<p class="total price">499 kr</p>        matches — one name out of the list
<p class="Price">499 kr</p>              no match — class names respect case

#priser { scroll-margin-top: 5rem; }

written together, with no space: all true of one element
p.price          a <p> that also carries .price
.card.is-open    an element carrying both classes
a#home           a link that also has that id

separated by commas: any one of them is enough
h1, h2, h3 { margin-top: 0; }
.card p 

.card p       a <p> anywhere inside .card, however deep
.card > p     a <p> that is a direct child of .card
h2 + p        the <p> immediately after an <h2>
h2 ~ p        any <p> after an <h2>, same parent

the space is a combinator, not decoration
.card.is-open one element with both classes
.card .is-open .is-open somewhere inside .card
