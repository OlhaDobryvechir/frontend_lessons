one declaration, and four things happen at once

.row { display: flex; }

the children line up in a row
they end up the same height
they shrink rather than wrap
float, clear and vertical-align stop applying to them
display: flex 

.row   { display: flex; }          a block-level flex container
.badge { display: inline-flex; }   an inline-level one
container / item 

.row {                   ← the container decides how the row behaves
  display: flex;
}

.row > * {               ← the items decide how each one behaves
}

every flex property belongs to one side or the other, never both
direct children 

<div class="row">
  <div>a</div>                 an item

  <div>                          an item
    <span>b</span>              NOT an item — it is inside one
  </div>

  loose text                    an item too, an anonymous one
</div>
defaults 

what display: flex already gives you, without another line

flex-direction:  row          side by side          → lesson 19
flex-wrap:       nowrap       shrink, never wrap    → lesson 18
justify-content: normal       packs at the start    → lesson 20
align-items:     normal       stretches to match    → lesson 20

the last two compute to normal, which in a flex container
behaves exactly as flex-start and stretch

and on every item
flex:            0 1 auto     natural size, may shrink, will not grow
turned off 

.row > .item {
  float: left;              ignored
  clear: both;              ignored
  vertical-align: middle;   ignored
}

margins between items never collapse, either
10px below one and 10px above the next is 20px, not 10px
inline-flex 

flex          the box is block-level: it starts a new line and fills the width
inline-flex   the box sits in the running text, as wide as its content

inside, the two behave identically. the difference is the box itself.
