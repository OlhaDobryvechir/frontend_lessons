width: 50%;                   half of — something. which is the whole question
width: 50vw;                  half of the viewport, whatever the parent says
width: calc(100% - 2rem);     mix them, and let the browser do the sum
px 

border: 1px solid #253040;
width: 320px;

a CSS pixel is a reference unit, not a hardware dot:
on a 2× screen the browser paints one of them across two device dots
% 

property                  the percentage is measured against

width, left, right        the containing block’s width
height, top, bottom       the containing block’s height
padding, margin           the containing block’s width   ← all four sides
font-size                 the parent’s font-size
line-height               the element’s own font-size
translate()               the element’s own size
height: % 

does nothing — the parent has no definite height to halve
.parent { }
.child  { height: 50%; }

works — now there is something to take half of
.parent { height: 400px; }
.child  { height: 50%; }        → 200px
vw vh 

1vw    1% of the viewport width
1vh    1% of the viewport height
1vmin  1% of the smaller of the two
1vmax  1% of the larger of the two

the parent is not consulted at all
.tiny-box .hero { height: 100vh; }   still the full viewport
100vw 

desktop: with a classic scrollbar, 100vw is wider than the content area
width: 100vw;     → a horizontal scrollbar appears
width: 100%;      → what you almost always meant

mobile: 100vh is measured as if the toolbars were hidden
height: 100vh;    → the bottom sits behind the toolbar
height: 100svh;   → the small viewport, toolbars showing
height: 100dvh;   → follows the toolbars as they come and go
calc() 

width:  calc(100% - 2rem);
height: calc(100vh - 64px);
margin-left: calc(50% - 160px);

the spaces around + and − are required
calc(100% - 2rem)    ✓
calc(100% -2rem)     ✗   −2rem reads as one negative number
calc(100%-2rem)      ✗

× and ÷ do not need them, and the divisor must be a plain number
calc(100% / 3)       ✓
calc(100px * 2)      ✓
calc(100% / 3px)     ✗
clamp() 

width: min(100%, 60rem);            never wider than 60rem
width: max(50%, 320px);             never narrower than 320px
font-size: clamp(1rem, 2.5vw, 2rem);  floor, preferred, ceiling

clamp(a, b, c) is exactly max(a, min(b, c))
