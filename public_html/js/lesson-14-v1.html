there are no numbers in here. there are no objects either.
setItem 

localStorage.setItem('n', 5);          stored as '5'
localStorage.setItem('b', false);      stored as 'false'
localStorage.setItem('o', { a: 1 });   stored as '[object Object]'
localStorage.setItem('u', undefined);  stored as 'undefined'

the nicer-looking way is the same thing, with one trap
localStorage.c = '3';               works — getItem('c') is '3'
localStorage.length = 99;            ignored. length is a real property.
localStorage.getItem('length')       null — nothing was stored

the rest of the object
localStorage.length      localStorage.key(0)     key(9) → null

localStorage.getItem('finnesikke')   null, not undefined

three traps, all from lesson 1
getItem('n') + 1                     '51'   text and text
Number(getItem('n')) + 1             6

if (getItem('b')) ...                'false' is a non-empty string → true
getItem('b') === 'true'              this is the check you want

getItem('n') === 5                   false. always false.
JSON 

the only way to store something that is not a string
localStorage.setItem('bruker', JSON.stringify(bruker));
const bruker = JSON.parse(localStorage.getItem('bruker'));

lesson 7 still applies: a Date comes back as text
{ navn: 'Åse', dato: new Date(0), f: () => {}, u: undefined }
   → {"navn":"Åse","dato":"1970-01-01T00:00:00.000Z"}
   the function and the undefined are simply gone

two ways this throws at you later
JSON.parse(getItem('finnesikke'))   null — survives, parses 'null'
JSON.parse('undefined')             SyntaxError
JSON.parse('[object Object]')        SyntaxError

so wrap the read once, and never again
const les = (k, reserve) => {
  try { const r = localStorage.getItem(k); return r === null ? reserve : JSON.parse(r); }
  catch { return reserve; }
};
